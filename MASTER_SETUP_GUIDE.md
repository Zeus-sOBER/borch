# Dynasty Universe — Setup Guide

This guide has been consolidated into the main **README.md** and the interactive **Setup Wizard**.

## Getting Started

1. Read `README.md` for the full project overview, environment variables, and deployment steps
2. Run `database/dynasty-universe-complete.sql` in your Supabase SQL Editor
3. Deploy to Vercel and set your environment variables
4. Visit `/setup` on your live site — the setup wizard walks you through everything interactively

## Need Help?

- `/setup` — Interactive setup wizard with health checks
- `/api/health` — Diagnostic endpoint that checks your env vars, database connection, and tables
